Project Overview

From Simple Script to Professional App

The goal was to transform a minimal CRUD assessment task into an enterprise-ready, aesthetically stunning web chatbot.

❌ Before (Legacy)

Basic unstyled HTML forms, simple exact regex matches, manual page reloads, and plain text raw responses.

✅ After (Upgraded)

Glassmorphic UI, flexible NLP parser handling quotes & possessive names, live user sidebar sync, and styled table responses.

System Capabilities

System Architecture

Technology Stack & Layers

Layer Technology Used Role & Description
Backend Core Python (Flask) REST routing, session management, and NLP parser logic.
Database SQLite3 Persistent storage for user schema (`name`, `email`, `phone`, `city`).
Frontend UI HTML5 + JS + Vanilla CSS Glassmorphism design system, AJAX async fetch, live sidebar sync.
Typography & Icons Plus Jakarta Sans Modern Google typography and HSL tailored color palette.
Data Schema

SQLite User Data Model

Structured SQL schema ensuring clean data integrity and instant lookups:

CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  email TEXT UNIQUE NOT NULL,
  phone TEXT,
  city TEXT
);

Pre-seeded with demo records: jhon.smith@xyz.com (Admin), samantha@xyz.com (Samantha), alex.j@xyz.com (Alex Johnson).
